# Ritik Kumar — Cyberpunk Game UI Portfolio (vanilla HTML/CSS/JS)

Preview: double-click `index.html`, or in VS Code use the Live Server extension (right-click index.html > Open with Live Server).

Edit content: everything (projects, skills, career log, badges, gallery) is in the data block at the top of `main.js`.
Add SheherSaathi / To-Do repo links in the `link` fields, and verified certificates in `BADGES`.

Terminal: click `>_` in the navbar. Commands: help, about, projects, skills, lab, career, contact, hacker, clear, exit.

Deploy (GitHub Pages): push these files to the repo root, then Settings > Pages > Deploy from branch > main / root.
